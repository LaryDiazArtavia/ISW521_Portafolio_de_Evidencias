# ISW521_Portafolio_de_Evidencias

Repositorio creado para el curso **ISW-521 Programación en Ambiente Web I** de la **Universidad Técnica Nacional (UTN)**.

Este portafolio reúne las principales prácticas, workshops, laboratorios, investigaciones y proyectos desarrollados durante el cuatrimestre, mostrando la evolución desde los fundamentos de la Web hasta el desarrollo de aplicaciones con JavaScript, TypeScript y Vue.

---

## Contenidos estudiados

### Unidad I — Fundamentos de la Web

Durante la primera unidad se estudiaron los conceptos fundamentales relacionados con el funcionamiento de Internet y las aplicaciones web.

Entre los temas vistos se encuentran:

* Diferencia entre **Internet y World Wide Web**.
* Evolución de la Web: Web 1.0, Web 2.0 y Web 3.0.
* Modelo **cliente-servidor**.
* Internet, Intranet y Extranet.
* URI, URL y URN.
* Sistema de nombres de dominio **DNS**.
* Protocolos TCP/IP.
* Diferencias entre TCP y UDP.
* HTTP y HTTPS.
* Métodos HTTP: `GET`, `POST`, `PUT`, `PATCH` y `DELETE`.
* Códigos de estado HTTP.
* Ciclo de una solicitud HTTP.
* TLS/SSL y comunicación segura.
* Servidores web como Apache, Nginx, IIS y Node.js.
* Puertos y tipos de hospedaje.
* Conceptos básicos de Serverless.
* Uso de Git y GitHub para almacenar evidencias del curso.

# Laboratorio 02 — World Cup 2026

Aplicación web desarrollada con **HTML, CSS y JavaScript Vanilla** que consume información desde una API REST del Mundial 2026.

### Tecnologías

* HTML5.
* CSS3.
* JavaScript.
* Fetch API.
* DOM.
* localStorage.
* API REST.

### Endpoints utilizados

```text
GET /get/teams
GET /get/games
GET /get/groups
GET /get/stadiums
```

### Pantallas desarrolladas

#### La Ruta del Campeón

Permite seleccionar un equipo y visualizar sus partidos, estadios y ciudades.

#### Rastreador de Goleadas

Analiza los partidos finalizados y muestra aquellos con diferencias importantes de goles.

#### El Muro

Genera un ranking de los equipos con menor cantidad de goles recibidos.

#### Analítica de Estadios

Calcula información de los estadios y su posible asistencia.

#### Radar de Empates

Filtra y agrupa los partidos que terminaron empatados.

### Resiliencia y manejo de errores

También se trabajó con:

* Manejo de errores HTTP.
* Reintentos.
* Backoff exponencial.
* Manejo del estado `429`.
* Respaldo mediante `localStorage`.
* Conservación de información ya mostrada cuando una petición secundaria falla.

# Proyecto Final — LasDosCaras

Como proyecto final del curso se desarrolló el frontend de **LasDosCaras**, una aplicación web construida utilizando tecnologías modernas.

## Stack principal

* Vue 3.
* TypeScript.
* Vite.
* Pinia.
* Vue Router.
* HTML.
* CSS.
* JavaScript / TypeScript.
* Fetch API / servicios HTTP.
* localStorage.

## Organización

La aplicación se divide principalmente en:

```text
src/
├── components/
├── models/
├── router/
├── services/
├── stores/
├── utils/
└── views/
```

### Components

Componentes reutilizables utilizados en diferentes partes de la aplicación.

### Models

Interfaces y tipos de TypeScript utilizados para representar la información manejada por la aplicación.

### Services

Servicios responsables de comunicarse con la API.

### Stores

Administración del estado global mediante **Pinia**.

### Router

Administración de navegación y rutas mediante **Vue Router**.

### Views

Pantallas principales de la aplicación.

# Aprendizajes

Durante el cuatrimestre se avanzó desde los fundamentos de cómo funciona la Web hasta el desarrollo de una aplicación moderna basada en componentes.

El proceso permitió trabajar de forma progresiva con:

**HTML → CSS → JavaScript → DOM → APIs REST → ES6+ → TypeScript → Vue**

Además de desarrollar interfaces visuales, se trabajaron aspectos como responsividad, accesibilidad, manejo de errores, persistencia de datos, modularización, consumo de servicios web y organización de aplicaciones frontend.

Este repositorio funciona como evidencia del proceso de aprendizaje desarrollado durante el curso **ISW-521 Programación en Ambiente Web I**.
